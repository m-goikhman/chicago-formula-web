Episode 2 location-specific prompts.

Place character prompt files into one of these folders:
- `default_ep2/`
- `university_ep2/`
- `alex_apartment_ep2/`

Prompt filename format:
- `prompt_<character_key>.md`

Examples:
- `default_ep2/prompt_susan.md`
- `university_ep2/prompt_james.md`
- `alex_apartment_ep2/prompt_james.md`
